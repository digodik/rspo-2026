# Контекст проєкту (курс «Технології розподілених систем та паралельних обчислень», 4 курс, НТУ ХПІ)

Ця репа використовується ТІЛЬКИ для цього предмета. Щотижня користувач дає посилання на нову практичну з шаблону викладача; її треба зробити повністю: код, реальні заміри, звіти, коміти, push. Наприкінці — рядок для чату (формат із README практичної) і коротке просте пояснення для захисту російською.

## Репа і завдання
- Репа: digodik/rspo-2026, створена з шаблона duban-r/rspo-2026-template.
- Завдання: https://github.com/duban-r/rspo-2026-template/tree/HEAD/praktyka/<номер-назва>
  README береться з raw.githubusercontent.com (https://raw.githubusercontent.com/duban-r/rspo-2026-template/HEAD/praktyka/<номер-назва>/README.md), якщо його немає в репі.

## Машина
- MacBook Air, Apple M4, 10 фізичних / 10 логічних ядер (без SMT), 16 ГБ, macOS.
- Системний Python 3.9.6. Brew немає, sudo не використовуємо.
- Для Numba (потрібен Python 3.10-3.14): uv + Python 3.12, venv у корені репи `.venv/` (в .gitignore), там numpy і numba.
  Усі скрипти практики 06 і далі запускати з venv: `.venv/bin/python <скрипт>`.

## Головна задача курсу
- Множина Мандельброта 1200x1200, MAX_ITER=300.
- Еталон — послідовна версія тижня 2: `praktyka/02-poslidovno/mandelbrot.py`
  (cx = (col/width)*3.5 - 2.5; cy = (row/height)*3.0 - 1.5; цикл з поверненням i).
  Будь-яка нова реалізація мусить проходити assert / np.array_equal з цим еталоном.
  Формули cx/cy треба повторювати РІВНО як в еталоні (інший порядок операцій дає розбіжні точки).

## Структура
- `2-potoky/` (практична 03), `3-protsesy/` (04), `praktyka/05-synhronizatsiya/` (05), `4-numba/` (06), далі `5-gpu/`, `6-vuzly/` тощо.
- Головна таблиця ВСІХ замірів — `zamiry.md` у корені. `praktyka/02-poslidovno/zamiry.md` тепер лише посилання на неї.

## Правила викладача
- Усі заміри тільки реальні, на цій машині. Ніколи не вигадувати числа.
- У кожній таблиці вказувати процесор, ядра, розмір задачі, кількість прогонів, що входить у замір.
- Оригінальні файли викладача не чіпати, правки тільки в копіях.
- На захисті питають за моїми числами, тож пояснення мають збігатися з реальними результатами.
